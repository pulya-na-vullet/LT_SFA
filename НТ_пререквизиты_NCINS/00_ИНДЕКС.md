# НТ пререквизиты — модуль NCINS в SFA (`ufr-eos-ul-ncins`)

**Комплект документов для передачи модуля на нагрузочное тестирование**  
Версия: 0.2  
Дата: 16.09.2026

---

## Назначение

Комплект описывает модуль **некредитного страхования ЮЛ в SFA / ЕОС.ЮЛ**
(`ufr-eos-ul-ncins`, UI «Страховки для бизнеса»). Это **не** модуль «Нефинансовые сервисы ЮЛ» (NSSFA)
и **не** платформа SFA ЮЛ целиком.

Структура разделов пререквизитов сохранена по эталону UMP
(`НТ пререквизиты - Worker ump-*-ncins-pa`). Форма подачи — **одна анкета для входа по модулю**,
как в шаблоне «Передача модуля на нагрузочное тестирование» и в примере анкеты NSSFA.
Отдельные постановки на каждый k8s-сервис не делаются: `gateway-router` и `access-checker` —
инфраструктура объекта тестирования, а не самостоятельные сценарии НТ.

## Что исправлено относительно черновика 0.1

1. Убрано имя NSSFA / «Нефинансовые сервисы» как название этого модуля.
2. Пять документов «по сервису» сведены в одну анкету + паспорт инфраструктуры (приложение Д).
3. Из колонки «Значение» убраны коэффициенты ×6 / ×9 / ×20, SLA 30/3/5/10 сек и прогноз ×1,3 —
   это не подтверждено аналитиком и не следует из кода.
4. ЧПН модуля зафиксирована как **заявки**: 15 000/мес → ≈89/час среднее, ≈180/час пик (из UMP).
   ЧПН по REST-методам SFA — `_TBD_`.
5. Добавлен сквозной контур SFA ↔ UMP: создание заявки, Kafka `SigningDocs` / `paymentFinished`,
   `POST /v1/ins-contracts`.
6. Заглушки разведены: что логично мокать, что на ЛТ обычно живое, что уже смотрит в `ufrulltmock*`.
7. Зафиксированы смешанные контуры в config (LT / INT / `*test`) и расхождение README vs values.
8. `xpin-const: XAAAAA` больше не трактуется как PIN тестового клиента.

## Источники

Использованы:

- helm-values и `configMap/` этого репозитория (`ufr-eos-ul-ncins-*`);
- 6 документов UMP «НТ пререквизиты - Worker ump-*-ncins-pa»;
- шаблон «Передача модуля на нагрузочное тестирование» v12;
- пример заведения задачи НТ ЕОС.ЮЛ;
- анкета NSSFA — **только как образец формы**, не как данные NCINS.

Не использованы как источник фактов: догадки о числе кликов/методов на заявку, SLA UMP-процессов
как SLA HTTP SFA.
